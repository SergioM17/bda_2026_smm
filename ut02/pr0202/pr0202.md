**Copiamos el archivo en el docker**

`docker cp .\Downloads\kaggle\vehicle_price_prediction.csv namenode:/root/proyecto_datos`


**copiamos el archivo en el sistema distribuido**

`hdfs dfs -put ./vehicle_price_prediction.csv /proyecto_datos`

**Vemos el contenido del archivo**

`hdfs dfs -cat /proyecto_datos/vehicle_price_prediction.csv | wc`

**Creacion de carpetas de procesado y backup**

`hdfs dfs -ls /proyecto_datos/backup`

**Copia del archivo en backup y mover el original a la carpeta procesados**

`hdfs dfs -mv /proyecto_datos/vehicle_price_prediction.csv /proyecto_datos/backup`
`hdfs dfs -cp /proyecto_datos/backup/vehicle_price_prediction.csv /proyecto_datos/procesados`

**Directorio compartido**

`hdfs dfs -mkdir /proyecto_datos/compartido`

**Recuperacion de datos**

`hdfs dfs -get /proyecto_datos/procesados/vehicle_price_prediction.csv ./recuperado_vehicle_price_prediction.csv`

**Control de acceso**

Verificamos los permisos
`hdfs dfs -ls -R /proyecto_datos` 

Dejar el archivo de backup accesible solo para ti (lectura y escritura)
`hdfs dfs -chmod 600 /proyecto_datos/backup/vehicle_price_prediction.csv`

Comprobar el cambio (debe aparecer -rw-------)
`hdfs dfs -ls /proyecto_datos/backup`
salida: `-rw-------   3 root supergroup  126967327 2026-10-27 09:09 /proyecto_datos/backup/vehicle_price_prediction.csv`

**Eliminacion de archivo**

`hdfs dfs -rm /proyecto_datos/temporal.txt`
